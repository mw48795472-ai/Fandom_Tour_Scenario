# 공연이력 리서치 원본

`SPEC.md` 는 조사 에이전트에게 준 출력 규격이고, `b1.tsv` ~ `b11.tsv` 는 배치별 원본입니다.
배치는 100개 아티스트를 10팀씩 나눈 것이고, `b11.tsv` 는 1차에서 무기록으로 나온 4팀의 재확인 배치입니다.

검증·병합은 `src/pipeline/merge_shows.py` 가 합니다 — 아티스트명·시도명·출처 URL·날짜 형식·
수집 기간·중복을 검사하고, 통과한 것만 `data/artist_show_history_v1.csv` 로 나갑니다.

병합 결과에 적용한 수동 보정은 `docs/DATA.md` 의 "검수에서 고친 것"에 적었습니다.
