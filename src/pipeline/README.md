# 파이프라인

작업 순서대로 돌아간 스크립트들입니다. 파일명은 작업 당시 순번이라 의미가 없어서,
무엇을 하는지 여기 적어 둡니다. 경로는 당시 작업 디렉터리 기준이라 그대로 실행하려면
조정이 필요합니다 — 산출물은 전부 `data/derived/` 에 있으므로 재현 없이도 값을 확인할 수 있습니다.
