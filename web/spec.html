01

문서 개요

1.1목적

본 명세서는 이미 산출된 분석 자산(팬덤 프로파일 100건, 근거 코퍼스 10,020건, POI·루트 목업, DID 파이프라인)을 재사용 가능한 서비스 구성요소로 정의한다. 새로운 분석 방법론을 제안하지 않으며, 결과보고서에서 확정된 산식과 임계값을 그대로 채택한다.

1.2범위

  • 포함 — 데이터 스키마, 지표 산식, 배치 주기, 내부 API, 화면 요소, 검증 게이트, 코드값 사전
  • 제외 — 인프라 구성, 인증·권한 상세, 예매처 제휴 계약, UI 비주얼 디자인, 개인정보 처리방침

1.3용어

용어정의
K 토픽LDA로 추출한 원 토픽. 팬덤 행동·담론의 주제 범주.
F 메타요인K 토픽을 코사인거리 기반 계층적 재군집화해 얻은 5개 파급경로(F1~F5).
페르소나팬덤별 상위 2개 F 조합을 사전 정의 조합표에 매칭한 규칙 기반 라벨. 통계적 재군집화가 아니다.
전환등급이벤트별 DID 결과에 부여하는 A/B/C 판정. 사업 성패가 아닌 노출 설계의 재현성 지표.
스냅샷근거 코퍼스의 특정 시점 적재본. 모든 지표는 스냅샷에 종속된다.

05

지표 산식

5.1~5.5는 결과보고서에서 확정된 산식이며 변경하지 않는다. 5.6~5.7은 본 서비스에서 신규 정의하는 산식이다.

5.1EvidenceScore — 충성도·파급효과 원점수

EvidenceScore(f) = Σt [ 1.0 + 0.5 · n_num(t) + 0.3 · n_kw(t) ]

n_num = 문장 내 수치표현 개수 · n_kw = 지표별 보너스 키워드 일치 횟수. 충성도 키워드 19종(기부·동원·매진·출범·창단·결성·총공·역사·지속·확장·1위·최초·신기록·밀리언셀러·팬클럽·팬카페·결속·충성·세대), 파급효과 키워드 18종(경제효과·매출·관광·지자체·앰버서더·모델·브랜드·팝업·협업·관중·방문·상권·지역·홍보대사·수익·투어·콘서트·소비).

5.2정규화

score_norm(f) = ( score(f) − min ) / ( max − min ) // 표본 100개 내 min-max

절대 크기가 아닌 상대 위치다. 4구획 임계값을 절대값이 아닌 표본 평균(loyalty 0.3710 / spillover 0.2661)으로 둔 것과 논리적으로 일치한다. 표본이 바뀌면 전 팬덤의 값이 재계산된다 — 시계열 비교 금지.

5.3Coverage Index

CoverageIndex(f) = 0.30·Lang + 0.25·Mkt + 0.20·Src + 0.15·Time + 0.10·Ent Lang(f) = − Σ pi · ln pi / ln(14) // 14개 언어 인용분포의 정규화 섀넌 엔트로피 Mkt (f) = 언급 지역 수 ÷ 6 // 일본·중화권·미국/북미·유럽·동남아·글로벌 Src (f) = 출처유형 수 ÷ 3 // 뉴스매체·커뮤니티/SNS·위키/레퍼런스 Time(f) = 언급 연도 수 ÷ 코퍼스 전체 연도 범위 Ent (f) = 제3자 기관·플랫폼 카테고리 수 ÷ 6

팬덤의 영향력이 아니라 데이터 커버리지를 나타낸다. M1 순위 산정에 직접 가산하지 않고, 커버리지 하위 구간(< 0.50)에 대해 결과 신뢰도 경고를 띄우는 용도로만 쓴다.

5.4FactorShare · FactorDiversity

FactorShare(f, m) = Σe∈f Σt∈m θ(d,t) / Σe∈f Σt θ(d,t) FactorDiversity(f) = − Σ pm ln pm / ln(M) // M = 5 dominant_factor(f) = argmaxm FactorShare(f, m)

5.5Member Concentration Index

MCI(g) = Σi∈g ( sharei )² // 허핀달-허쉬만 방식

완전균등분포에서도 1/멤버수가 되므로, 멤버 수가 다른 그룹 간 직접 비교는 하지 않는다. 동일 규모 구간 내 상대 비교로만 사용한다.

5.6RegionFit — 신규

RegionFit(f, r) = 0.30·A + 0.25·B + 0.20·C + 0.15·D − 0.10·E A 연고밀착도 = regional_index.share (지역 r 기준) B 업종적합도 = persona_product_map(f) · LQ_fit(r) // 부록 A.3 × 지역 LQ C 파급효과 = fandom_profile.spillover D 언어적합도 = Σ (language_index.share × 지역 인바운드 국적 비중) E 집중리스크 = aux_index.member_concentration (MCI) 게이트: coverage < 0.50 → 신뢰도 경고 표시 activity < 80 → 후보에서 제외

v0.1 초기 가중치다. 파일럿 이벤트 12건 이상 축적 시 M3의 전환등급을 종속변수로 재적합한다. 가중치 변경은 문서 개정으로만 반영하고, 코드에 상수로 박지 않는다.

5.7전환등급 — 신규

metrics = { search_cnt, visitor_cnt, spend_amt } A ∀m ∈ metrics: effect_pct(m) > 0 AND min(p_randomization) < 0.05 AND parallel_ok B 일부 지표만 (+) 또는 방향 불일치 C 주요 지표가 음(−)이며 p_hac < 0.05 parallel_ok = false → 등급 미부여, "정황적 근거"로 표기

08

화면 명세

S-04는 RESCENE Route 목업이 이미 구현한 화면이므로, 목업의 요소를 그대로 요구사항으로 기술한다.

S-01

지역 진단 (M1)

  • 입력 — 시도·시군구 선택, 사업유형(위촉/촬영유치/공연유치), 예산 구간
  • 결과 목록 — RegionFit 상위 10건. 각 행에 점수, 4구획 배지, 페르소나 배지, 권장 상품유형
  • 점수 분해 — A~E 5개 항의 기여도를 가로 누적 막대로 표시. 감점 항(E)은 반대 방향
  • 경고 — coverage < 0.50, MCI 상위 구간, 지역다양성 극단값에 대한 인라인 경고
  • 근거 열람 — 행 확장 시 해당 팬덤·지역 근거 문장 5건과 원문 링크
S-02

팬덤 상세 (M1)

  • 3축 위치 — 충성도·파급효과·요인다양성. 세 축을 합산한 종합점수는 표시하지 않는다 (요인다양성과 파급효과의 상관 r=0.461 때문)
  • F1~F5 레이더 — 100개 팬덤 평균 오각형을 점선으로 병기
  • 지역 · 언어 분포 — 시도별 언급 막대, 언어별 근거 수와 해외 비중
  • 보조지표 7종 — 업종 구성, 결속 활동유형 A~E, 매체 도메인 수
  • 과거 이벤트 — 해당 팬덤 관련 did_result 이력과 등급
S-03

루트 편집기 (M2)

  • 3분할 — 좌: POI 검색·필터(7개 카테고리) / 중: 지도 / 우: 일차별 정차 목록
  • 일차 배분 — dwell_min 합계와 이동시간으로 일차 초과 여부를 실시간 표시
  • 규칙 검사기 — food·stay 각 1건 이상, 교통 허브 연결 여부, 좌표 출처 누락 POI를 발행 전 차단
  • 언어 설정 — language_index 상위 3개 언어를 기본 제안, 담당자가 가감
  • 미리보기 — 공개 앱과 동일 렌더링, 언어 전환 확인
S-04

공개 루트 앱 (M2) — 목업 구현 완료

  • 지역 전환 — 전국 / 시군 탭. 목업 기준 7개 시군
  • 카테고리 필터 — 역사·문화유산 / 해양·자연경관 / 힐링·생태·체험 / 테마파크·액티비티 / 로컬상권·먹거리 / 숙박·로컬체험 / 팬소통
  • 장소 상세 — 사진과 출처, 설명, 운영시간·요금, 권장 체류시간, 연계 영상(조회수·게시일), 좌표 출처 문구
  • 일정 구성 — 일차별 코스 편집, 총 거리·예상 시간·경유지 수 표시
  • 이동 — 출발지 선택(주요 역·터미널·공항 리무진), KTX·SRT·고속버스 예매 딥링크, 자가용/대중교통/도보 전환
  • 숙박 — 일차별 숙소 지정, 유형·지역·가격 하한 표시, 예약 딥링크
  • 언어 — ko / en / ja / zh 전환. 장소명·설명·운영시간 문자열까지 사전 매핑
  • 추가 요구 — 루트 로그 전송, UTM 파라미터 보존, 공유 QR
S-05

이벤트 등록 (M3)

  • 입력 — 이벤트 유형, 처리지역, 날짜, 연계 루트 ID
  • 통제군 제안 — 사전 평행추세 검정을 통과한 후보를 검정통계량과 함께 3~4개 제시하고 담당자가 선택
  • 설계 자동 선택 — 사전 관측구간이 확보되지 않으면 YoY 설계로 자동 전환하고 그 사실을 표기
  • 윈도우 — 체류형/첫날집중형 프리셋. 기본값은 페르소나로부터 제안
S-06

전환 원장 대시보드 (M3)

  • 등급 요약 — 기간 내 이벤트의 A/B/C 분포
  • 이벤트 카드 — 3지표 효과크기, p값 3종, Event Study 시계열
  • 방향 일관성 표시 — 세 지표의 부호를 한 줄로 병기해 "일부만 양(+)"을 즉시 식별

9.1실루엣 게이트

K→F 재군집 결과는 실루엣 계수 0.267(K=10 · M=5 기준값)을 통과하지 못하면 채택하지 않는다. 코퍼스가 1% 미만으로 변해도 여러 K 토픽이 하나의 Meta Factor로 묶이는 현상이 반복 관찰되었기 때문에, 내재된 불안정성을 통계적으로 해소하려 하지 않고 기각 규칙으로 관리한다.

9.2DID 강건성 3중 확인

  • HAC 회귀 — Newey-West 표준오차로 일별 데이터의 자기상관 보정
  • 무작위추론 — 가짜 위촉일 1,000회 추출, 실제 계수의 분위 확인 (거제 상위 1.6%)
  • 플라시보 연도 — 전년 동기간에 동일 검정, 유의하면 결과 기각

HAC는 점근적 정규성 가정에, 무작위추론은 실제 표본 분포의 재구성에 의존하므로 상호보완적으로 해석한다. 셋 중 하나만으로 등급을 부여하지 않는다.

9.3스냅샷 정합성 — 필수 확인

현재 두 산출물의 스냅샷이 다르다

Persona 아티팩트는 근거 코퍼스 7,350건 시점에서 K=10 · M=5 · 실루엣 0.267로 산출되었고, 3D 포지셔닝 아티팩트는 10,020건 시점의 값이다. 후자 스냅샷의 재군집 결과는 K=8 · 실루엣 0.046으로 9.1의 게이트를 통과하지 못한다.

그 결과 두 테이블의 팬덤 목록도 완전히 일치하지 않는다 — 3D에만 있는 팬덤 3건(몬스타엑스·빈지노·투어스), Persona에만 있는 팬덤 3건(BE'O·pH-1·한로로).

운영 규칙. ① 페르소나·F비중 계층은 게이트를 통과한 스냅샷에 고정한다. ② 충성도·파급효과는 최신 스냅샷을 쓰되 snapshot_id를 함께 노출한다. ③ 두 계층을 조인하는 모든 조회는 양쪽에 존재하는 팬덤만 반환하고, 제외된 건수를 응답 메타에 포함한다. ④ 화면에는 두 스냅샷의 기준 시점을 병기한다.
